# 使用与迁移

## 安装和升级

下载并在 Root 管理器刷入 `HyperFont-Control-v2.4.1.zip`，然后手动重启。安装包不附字体。不要同时启用 MFGA 或其他字体覆盖模块。

2.2.0 起，发布新正式版后，Root 管理器的模块页会直接提示更新，点更新即可；之后同样手动重启。

覆盖升级保留 `/data/adb/hyperfont-control` 中的字体库和设置，并重建最近提交的配置。未提交草稿不参与升级生效。重建校验失败会中止安装；不要忽略安装错误。

## 导入字体

点“字体库”右上角“导入字体”，进入单独的导入页，自动列出手机 Download 文件夹（含一层子文件夹，按文件夹分组）里的 TTF、OTF、TTC、OTC 文件；勾选、“全选此文件夹”或“全选未导入”后点“导入所选”，完成后自动回到字体库并展开刚导入的那组，按路径直接导入，不经过 WebView 上传，大文件也很快。其他位置的文件可点“其他位置…”用系统文件选择器导入。系统会识别字体面、真实字重、斜体和可变轴。

字体库按字体家族自动分组，点开一组可逐个移除，也可整组移除；移除前会提示该字体是否正被配置使用。

静态多字重：进入相应分类选择“静态多字重”，再选“字体家族”，九档会自动填好（先按文件自带的字重，再看文件名里的 Light、Bold、W3、300 等，其余按文件名从细到粗；推断出的档标“请核对”），然后在“② 字重设置”逐档微调。下拉列表显示导入时的文件名。可变字体的自定义九档每档有滑块，按住圆点拖动，每次移动 25，也可在数字框输入精确值。导入成功后，字体以内容哈希保存到 `/data/adb/hyperfont-control/library/`，以后不依赖 Download 中的原文件。

如果关闭面板中断导入，可以使用“清理未完成导入”。此操作也会取消其他面板正在进行的分块导入，已入库字体和配置保留。超过 24 小时无活动的上传会在新建上传时自动清理。

## 字重设置

四个分类可以独立使用系统字体、可变字体或静态多字重。中文只接管汉字及相关标点，英文分类接管相应拉丁字符，原生其他语言与表情继续补字。

可变字体：选择正体文件，有真实斜体时另选斜体。九档模式下，左侧是应用请求的逻辑字重，右侧是字体实际使用的 `wght` 值。例如逻辑 400 → 450，表示常规文字使用源字体 450 轮廓。映射必须在真实轴范围内且不能逆序；调整常规档后也应检查其余档位的关系。连续模式让系统按可变轴选择；切换模式会保留自定义映射。

静态字体：有哪个实际字重文件就配置哪个，不能只改标签制造不存在的轮廓。例如锤子黑体六个文件可配置 100、300、400、500、700、900。选择“最近字重”后缺少的 200、600、800 由 Android 匹配，具体选择遵循系统匹配规则；这不是插值生成新的字重。选择“缺档拒绝”则需要补齐要求的档位。

等宽分类应选真正的等宽字体。如果选 Anthropic Sans 等比例字体，数字或代码列宽不会自动对齐。字体本身的行距和轮廓保持原样。

## 保存、生效与恢复

“保存草稿”只保存编辑；“提交更改”才生成待生效配置。提交时会校验字体、XML 和 Android 实际解析结果，成功后由你手动重启。

“字体覆盖已挂载”表示当前读取到的字体表和字体文件内容符合生成清单；应用自带字体或独立绘字仍需实际观察。顶部“已暂停这份字体配置”表示上次尝试没有完成 Android 开机，启动保护已跳过同一份配置。先调整或重新提交，再手动重启重试。

如要恢复，在“诊断与恢复”选择“恢复系统字体”，提交后手动重启。字体库保留。完全卸载则由卸载脚本清理本模块拥有的数据目录，临时覆盖在重启后消失；请在卸载前自行保留需要再次导入的源字体。

遇到卡住的那次启动，仍需手动重启或使用 Root 管理器安全模式停用模块。启动保护在下一次执行模块启动脚本时生效，不会主动重启手机。强制在 Android 开机完成前重启，也可能触发保护。

## 导出与迁移

配置导出保存到 Download。配置内的字体 ID 是内容哈希，不包含字体文件。迁移到另一台设备时，先导入相同字体文件，再导入配置、检查并提交；不要直接复制上一台设备生成的 XML 或系统基线。

系统更新导致指纹或原始字体表变化时，模块停止覆盖。恢复系统字体并重启后，使用“重新识别系统”，然后重新提交配置。错误诊断可在面板导出；分享前检查其中的设备信息。

## 2.5.0 字重预览与方案

在“字体设置 → 分类 → ② 字重设置”顶部可以编辑预览文字，选择请求字重与正斜体，展开九档对照。预览读取实际导入文件；缺失斜体标注模拟倾斜，静态缺档采用最近的同样式字重（等距取较轻档）。系统模式展示 WebView 当前字体，实际应用需重启验收。

自定义九档每行减/加按钮调整 50，超出真实轴范围时封顶。滑块仍按 25 调整，数字框支持精确小数。“默认”只恢复当前分类的九档映射，超出字体范围的 100–900 档会截到边界。

字体设置总览“我的方案”可保存当前四分类组合、更新、另存、重命名或删除；“载入编辑”不提交，“一键切换”校验并提交，需手动重启。尚未保存的编辑可另存后切换。方案引用的字体不能删除。

展开“字体与方案备份还原”，点击“完整备份 ZIP”将全部字体原文件、方案及已保存的草稿/当前/待生效配置快照写入 Download。备份不包含屏幕上尚未保存的编辑，请先存草稿或保存方案。单字体上限 256 MiB，完整包上限 4 GiB。

还原可从 Download 选择 ZIP，或使用“其他位置”。校验通过后确认合并；已有字体按 SHA-256 去重，重复方案跳过，同名不同配置保留“还原副本”。配置快照转为可选择的方案，不覆盖当前编辑、已生效或待重启状态。大包推荐放在 Download，避免 WebView 分块上传耗时。原 JSON 导入/导出只包含配置，不包含字体文件。

调整某一档的减/加按钮、滑块或数值时，顶部预览自动切到该请求字重；实际轴值例如 700→775 会同步显示。静态字体更换正体/斜体文件时，预览同步到该档及该样式。整体调整和默认恢复保留当前预览档位。也可随时手动选择预览档位；单纯滚动或聚焦输入框不会改变预览。

2.5.2 优化预览加载：支持的管理器直接读取字体文件，返回最近浏览过的字体复用短期缓存。首次大字体仍需文件读取和 WebView 字体解析；不支持快速通道的宿主会自动采用兼容方式，无需手动设置。
